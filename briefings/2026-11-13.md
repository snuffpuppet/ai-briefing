### 1. Decision Models Hit Full Market: Three Providers, One Shared API Contract

**Source:** Latent Space (AINews, Jev Revolution) · Simon Willison's Weblog · **Published:** 2026-11-11 to 2026-11-12 · **Read time:** ~7 min

**Elevator pitch** — Google's Gemini Decision 1 joins TypeSafe's Jev and OpenAI's GPT-6 Luna Decisions API in a new category of AI endpoint that returns typed decisions instead of text, with pricing modeled on input tokens only.

**Opinion vs. fact**
- [FACT] TypeSafe's Jev launched September 15, 2026; supports three question types: yes/no ("Noul," returns a probability), multiple-choice, and rubric scoring
- [FACT] Jev pricing: $0.042/M input tokens; output tokens cost nothing
- [FACT] OpenAI's Decisions API runs on GPT-6 Luna; response time ~150ms; generally available from October 22, 2026; supports image input
- [FACT] OpenAI Decisions API pricing: $0.10/M input, output free
- [FACT] Google's Gemini Decision 1 supports the same three question types as Jev, reuses Jev's term "Noul" for yes/no, and prices at $0.10/M input, output free
- [FACT] At AI Engineer (November 2026), Cloudflare demonstrated using a decision classifier to triage build failure steps; Glean and others showed production Jev deployments
- [OPINION] The convergence on Jev's API vocabulary suggests TypeSafe established the category's design contract before the larger players arrived
- [OPINION] Only Jev claims calibration against real outcomes rather than model self-scoring (single secondary source; treat as contested until TypeSafe publishes methodology)

**References** — Simon Willison's Weblog (direct API inspection); Latent Space AI Engineer Code Summit coverage; Vercel AI Gateway documentation; Diogo Almeida (Jev creator, TypeSafe AI); Cloudflare and Glean production case studies

**Justifications** — Simon Willison's direct observation of Gemini Decision 1 reusing "Noul" is the strongest evidence of API convergence; this is a verifiable naming decision, not an interpretation. Pricing data for all three providers is consistent across multiple independent sources. The calibration claim for Jev is from a single secondary source and is contested.

**Core points**
- Decision models return typed outputs—probability, selection from a list, or rubric score—rather than free text; designed for high-frequency classification in agentic pipelines
- Three providers now offer compatible API surfaces; Jev is cheapest ($0.042/M) vs. $0.10/M for OpenAI and Google
- Input-only pricing (zero output cost) makes continuous inline classification economically viable at scale
- Production uses surfaced at AI Engineer: build failure triage (Cloudflare), ticket routing, agentic action selection (Glean)
- Cross-provider portability looks achievable from day one given the shared API vocabulary

**Impact** — For anyone designing agentic workflows, this category fills the gap between full LLM generation and hard-coded logic: faster and cheaper than a general model for structured choices, more robust than rule engines for ambiguous inputs. If you're routing support requests, selecting tools in an agent loop, or evaluating intermediate outputs, the economics here are significantly better than calling a general model. For a Solutions Architect designing AI-integrated OSS systems—where event classification and decision routing are common—this is now a viable component, not a research topic. The shared API surface means you can test across providers without an abstraction layer. Run Jev and Luna head-to-head on your classification tasks before the category matures further.

**Impact** — This directly removes friction from local development against AWS services for anyone who lost access to LocalStack's free tier earlier this year. The authorship story is also independently significant—AWS generated 16M+ lines of production infrastructure code in three weeks of agent operation, with an independent fidelity benchmark as the quality gate. For teams designing AI-augmented development workflows, this is a concrete data point on what autonomous agent swarms can and cannot deliver today.

### 3. Gemini 4 Hydrogen Completes Google's Low-Cost Tier

**Source:** Google DeepMind Blog · Ars Technica · Simon Willison's Weblog (llm-gemini 0.37) · **Published:** 2026-11-12 · **Read time:** ~4 min

**Elevator pitch** — Google launched Gemini 4 Hydrogen, the low-cost member of the Gemini 4 family, at $1.50/$7.50 per million tokens with a 1M-token context window, replacing Gemini 3.8 Flash.

**Opinion vs. fact**
- [FACT] Gemini 4 Hydrogen launched November 12, 2026
- [FACT] Pricing: $1.50/M input, $7.50/M output, $0.075/M cached input
- [FACT] 1,048,576 token context window
- [FACT] Available in the Gemini API (model ID: gemini-4-hydrogen), Gemini app, and Google Search
- [FACT] Hydrogen did not receive the security-conscious staged rollout used for Argon and Carbon
- [FACT] Gemini 4 Carbon introductory pricing ($2/$10/M) expires November 30, 2026; standard price becomes $4/$20/M from December 1
- [FACT] Gemini 4 Argon introductory pricing ($2/$10/M) also expires November 30, 2026
- [OPINION] Simon Willison: Gemini 4 pricing is confusing given the multiple tiers and transition dates
- [OPINION] Hydrogen's faster rollout relative to Argon/Carbon suggests Google views this tier as lower-risk

**References** — Google DeepMind Blog (official announcement), Ars Technica, Simon Willison's llm-gemini 0.37 release notes (pricing tables observed directly)

**Justifications** — Pricing comes from Simon Willison's direct observation of the Google API pricing page (the most reliable source for real-time pricing) and confirmed by two independent secondary sources. The December 1 pricing cliff is documented in Simon Willison's pricing table comparison.

**Core points**
- Gemini 4 Hydrogen: $1.50/$7.50/M—25% cheaper than Carbon/Argon at current introductory pricing
- After December 1, Argon/Carbon price doubles to $4/$20/M; Hydrogen remains at $1.50/$7.50/M
- 1M token context window, consistent with rest of the Gemini 4 family
- Replaces Gemini 3.8 Flash as the high-volume, cost-sensitive tier
- Full Gemini 4 tier structure as of today: Hydrogen ($1.50/$7.50) < Carbon/Argon introductory ($2/$10) < Carbon/Argon standard from Dec 1 ($4/$20)

**Impact** — The December 1 pricing cliff is actionable: if you're evaluating Gemini 4 models for a cost-sensitive workload, the next two weeks are the window to benchmark Hydrogen against Carbon/Argon while prices are roughly comparable. If Hydrogen handles your tasks adequately, you lock in a 50–70% cost advantage over those tiers once their introductory prices expire. For context-heavy workloads (large document analysis, long-horizon agentic sessions), the $0.075/M cached input rate is the most significant number. At 1M token context, Hydrogen is now competitive with any long-context provider for price-performance on throughput workloads.
