Weakness: this is a post-hoc workaround for an agent behavior ideally addressed at the prompt or agent-configuration level.

**Core points:**
- Coding agents embed internal context (private IDs, task planning notes, issue references) in commit messages by default
- commit-rewriter provides a CLI cleanup step for before publishing or making history public

- Addresses a specific observed failure: Datasette security release commits containing private repo references

**Impact:** Low direct architectural impact, but signals a growing operational problem as coding agents generate commit history at scale. If you're formalizing agent-assisted development standards for your org, commit-message hygiene belongs on the checklist alongside code review and test coverage requirements.
